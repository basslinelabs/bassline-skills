# plan

Fill the brief and lay out one plan line per ad.

**Gates:** Brand, Brief.

## Steps

1. **Brief.** Ask once, in one short message with choices, for anything missing:
   - Goal: launch, seasonal, evergreen (more than one is fine)
   - Funnel stage: top, middle, bottom (more than one is fine)
   - Angle: from `message`, or the user's words
   - Size: 1:1, 3:4, 9:16, 16:9, 2:3 or 3:2 (default 3:4 for feed)
2. **References.** Use the collection from `curate`, or a recipe from `list_recipes`. One format per ad.
3. **Lines.** One line per ad, up to 12:

| # | Reference | Format | Product | Headline | Body | Size |
|---|---|---|---|---|---|---|

4. Show the plan. The user edits lines by number, adds lines or drops lines.

## Rules

- Count lines exactly. Adding one size adds one line.
- A line with no reference cannot be made yet. Say "needs a reference".

Next: `adapt` to see each line before and after.
