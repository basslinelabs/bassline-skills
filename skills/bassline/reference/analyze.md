# analyze

Break down one inspiration ad so the user sees what makes it work and what could carry over.

**Gates:** none.

## Steps

1. Find the ad: from a collection (`get_swipe_collection`), a search result (`search_reference_ads`), or an image the user gave.
2. Look at the image. Write the breakdown:

| Part | What it shows |
|---|---|
| Format | library format name |
| Hook | first thing the eye reads |
| Angle | promise or tension |
| Layout | where product, text and people sit; crop; negative space |
| Light and color | direction, softness, main colors |
| Type | weight, size, how many lines |
| Copy | each text line |
| Why it works | one line, as a mechanism |
| Carries over | what any product could keep |
| Does not carry over | things tied to that brand, person or claim |

3. Separate what you see from what you guess. Mark guesses with "likely".

## Rules

- A person in the ad is not a model the user may copy.
- Offers, prices and ratings in the ad never carry over as claims.

Next: `adapt` with this ad, or `curate` to add it to a shortlist.
